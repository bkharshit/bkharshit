I like turning complex problems into simpler, more efficient systems.

My experience spans **full-stack development, distributed systems, Kubernetes, messaging platforms, automation, and enterprise production infrastructure**. For the past few years I've built scalable applications and high-throughput backend infrastructure, focusing on how systems scale, where they break, and how to make them resilient.

Now I'm exploring **AI engineering and agentic systems**, bringing the same engineering mindset to software that can reason, automate workflows, and work alongside people.

> I learn by building, breaking, and rebuilding things until they work.

## 🏢 At Lowe's

I work across application development and production infrastructure:

- **Session replay at scale:** customised, deployed, and operate an in-house build of [OpenReplay](https://github.com/openreplay/openreplay), scaling it from a single session to **3M+ sessions per day** on Kubernetes, Kafka, and ClickHouse.
- **Chaos engineering:** built tooling to deliberately break production-like systems and prove they recover.
- **AI and developer tooling:** building agent orchestration, conversational BI features, and MCP integrations.
